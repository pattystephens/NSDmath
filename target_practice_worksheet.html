🟢 Outer Ring — Procedural & Direct Application

1 point each
Q1
Write the number 460,053 in expanded form.
Break each digit into its place: hundred-thousands, ten-thousands, thousands, hundreds, tens, ones. Skip any place that's a zero.
Q2
Write the number 730,812 in word form.
Read the number in periods, left to right: the "thousands" period first, then the ones period. Say "thousand" once, right after the first period.
Q3
Write the standard form for one hundred forty thousand, one hundred four.
"One hundred forty thousand" fills the thousands period. "One hundred four" fills the ones period — watch out for the missing tens digit.

🟠 Middle Ring — Multi-Step & Contextual Application

2 points each
Q4
Maya recorded a visitor count as 600,000 + 40,000 + 300 + 9. Marcus wrote the word form as "six hundred forty thousand, four hundred thirty-nine." Who is correct? Explain the mistake.
Rewrite Maya's expanded form as a standard number first, digit by digit, then compare it place-by-place to what Marcus said.
Q5
Combine the value of the digit in the ten-thousands place of 102,453 with the value of the digit in the hundreds place of 640,739. Write the final sum in expanded form.
Find each digit's actual value (not just the digit itself), then add those two values together.
Q6
Order these three numbers from least to greatest: 45,039, 39,012, and 76,005. Use comparison symbols (< or >) to show your answer.
All three numbers have 5 digits, so compare the ten-thousands digit first. Only move to the next place if there's a tie.

🔴 Bullseye — Extension, Justification & Non-Routine Thinking

3 points each
Q7
Create a 6-digit number that meets all four clues:
  • It has a 0 in the ten-thousands place.
  • The value of the hundred-thousands digit is 700,000.
  • The ones digit is 3 times the tens digit.
  • When written in expanded form, the sum of all digits used is 20.
Lock in the digits you know first (hundred-thousands = 7, ten-thousands = 0), then use guess-and-check with the remaining clues to find the tens/ones pair.
Q8
Sam says: "In 460,053, the zero in the thousands place means the entire thousands period has no value." Is Sam correct or incorrect? Explain using place value concepts.
The thousands period has two digits: thousands and ten-thousands. Check both digits in that period, not just one.
Q9
Write a 6-digit number in standard form that contains a zero in the hundreds place. Then write its word form and expanded form, showing how the zero affects both forms.
In expanded form, the zero place simply disappears (you don't write "+ 0"). In word form, it just doesn't get its own word.
